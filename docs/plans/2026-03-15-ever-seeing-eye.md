# Hydra Concept: The Ever-Seeing Eye

## Status

Preserved on branch `codex/ai-core-lattice`.

Primary implementation lives in `src/renderer/src/panels/AICoreNode.tsx` as the current experimental AI-core visualization.

## Description

This version of Hydra reads less like a generic AI widget and more like a vigilant synthetic eye suspended inside a scanning lattice.

The visual qualities worth preserving:

- A contained spherical wireframe rather than a loose floating mesh
- Dense internal linework that suggests perception, analysis, and memory
- Sweep-line motion across the sphere, like an active scan or retinal pass
- A feeling that the system is watching, tracking, and protecting the operator
- A slight ominous intelligence without turning into horror or parody

## Narrative Framing

Codename: `The Ever-Seeing Eye`

Comic interpretation:

- Hydra is not just a dashboard assistant
- Hydra is the eye that never blinks while the operator is deep in multi-agent work
- It sees process drift, model instability, endpoint failures, and workload pressure before the operator does
- When Yennefer speaks through Hydra, the eye is effectively focusing

Possible tagline:

`Hydra keeps watch while the swarm works.`

## Product Use

This should remain available as a visual direction even if the main AI page evolves.

Potential future uses:

- Alternate AI-core theme or skin
- Story/comic splash panel
- Loading or invocation state for Yennefer
- Marketing image for Hydra as a living operations shell

## Next Improvement Ideas

- Add semantic node color to show health, inference flow, repair activity, and offline edges
- Make link pulses travel through the lattice instead of only brightening locally
- Tie motion intensity to live signals such as agent count, memory pressure, or audio/beat response
- Increase the illusion of depth so the sphere feels volumetric instead of flat
