# HELM v6.1.0

Grid now opens **Listening Ports** in a grouped list. See which services listen beyond this Mac and how many LAN and internet connections HELM observed. The list marks connection data as unavailable when the monitor cannot report it.

- Open the optional 3D map to explore the same listeners. The list remains available if the map cannot load.
- Select a service to see its bind scope, process, and any matching firewall rule by name. Secure View hides bind addresses.
- Connection counts reflect a snapshot. Firewall and router settings can still block access to a listening port.

## Install on macOS

1. Download `helm-6.1.0-arm64.dmg` from the release assets. The download requires Apple Silicon and macOS 12 or later.
2. Open the DMG and drag HELM to Applications.
3. Open HELM and choose **Grid → Listening Ports**.
