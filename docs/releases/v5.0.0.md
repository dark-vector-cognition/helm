# HELM v5.0.0

Released October 16, 2026.

HELM v5.0.0 is Helm Light, the open-source release.

## Highlights

- Apache License 2.0. HELM moves from PolyForm Noncommercial 1.0.0 to Apache-2.0. See `LICENSE` and `NOTICE`.
- First run works without a model. The app starts and every page renders with no model configured. AI briefings are optional and work with any OpenAI-compatible server. With nothing configured, HELM only checks this machine on the default port and never scans your network.
- Electron 41.10.7 (from 35.7.5), `better-sqlite3` 12.11.1, and refreshed build tooling. Node.js 22.12 or newer is required.
- Windows code paths for the port, network, process, battery, disk, and firewall monitors, covered by unit tests.
- Tighter agent detection and quieter notification defaults.
- A blank remote vault host can no longer start an `ssh` call.

Helm Go, the full signed build with auto-update and support, is coming soon.

## Upgrading

- Install Node.js 22.12 or newer, then run `npm install` again.
- The model endpoint is no longer set by default in `.env.example`. If you want AI briefings, set `LM_STUDIO_URL` to your server.
- The optional voice persona briefing mode and its `Cmd/Ctrl+Y` shortcut were removed. The standard briefing is unchanged.

## Validation

- `npm ci`
- `npm run typecheck`
- `npm test`
- `npm run build`
