# HELM v6.2.0

Open **Agent runs** to review completed work. When evidence is available, the review card shows the captured Git diff, recorded commands, and reported test exit codes. Choose **Accept** or **Request follow-up** to record your decision.

Secure View hides raw evidence on screen. Captured evidence stays in the local run journal. Use a trusted worktree for Git capture.

## Install on macOS

1. Download `helm-6.2.0-arm64.dmg` from the release assets. The download requires Apple Silicon and macOS 12 or later.
2. Open the DMG and drag HELM to Applications.
3. Open HELM and choose **Agent runs**.
