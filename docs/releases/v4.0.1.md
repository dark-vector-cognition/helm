# HELM v4.0.1

Released March 21, 2026.

HELM v4.0.1 is the radio-home patch release. It removes the hardcoded receiving endpoint from the signal map and replaces it with a persisted operator-configured home location.

## Highlights

- Added a first-run popup on the `Radio` page for setting the saved home endpoint label, latitude, and longitude.
- Persisted the radio home endpoint in HELM config so the signal map uses user input instead of a built-in location.
- Updated the signal globe to handle an unset home endpoint cleanly and prompt for configuration when route mapping needs it.

## Validation

- `npm test -- src/main/config.test.ts`
- `npm run build`
