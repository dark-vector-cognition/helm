# HYDRA v3.1.0

Released March 18, 2026.

Hydra v3.1.0 is the shell refresh release. It tightens the chrome language across the app, makes skins coherent, and turns `FM Radio` into a real desktop audio surface instead of a novelty panel.

## Highlights

- Reworked the shell into a tighter machine-chrome presentation with a clearer hierarchy across header, nav, scorecards, panels, and the command palette.
- Expanded the skin system to `Deck`, `Orbiter`, and `Forge`, with persisted shell-wide theming instead of one-off visual swaps.
- Added a dedicated `FM Radio` page with a Winamp-style stereo relay layout, presets, search, transport controls, manual stream loading, and local MP3 import.

## Playback And Reliability

- Added a main-process localhost radio relay so remote streams, manual URLs, and local files play through a stable Electron media path.
- Added native audio-file picking, persisted local-library entries, and a singleton audio engine so playback survives navigation.
- Allowed loopback media in the renderer CSP and fixed startup issues that could block playback or leave Hydra visually absent on launch.
