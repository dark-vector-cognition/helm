# HELM v4.0.0

Released March 21, 2026.

HELM v4.0.0 is the product-line reset release. It turns the old Hydra shell into a cleaner operator system with page ownership, persistent local history, real agent drill-down, and stronger infrastructure visibility.

## Highlights

- Renamed the product from `HYDRA` to `HELM` across shell identity, config surfaces, and UI copy.
- Collapsed the shell into owned pages so the app stops repeating the same panels everywhere.
- Added the `Phantom` skin and tightened the shell chrome across header, navigation, scorecards, and page framing.
- Rebuilt Swarm so agents open into actual detail: PID, command, working directory, ports, goals, and timeline context.
- Reworked Grid around a live traffic-topology view with scoped `loopback`, `LAN`, and `internet` peers.
- Replaced filler ticker content with local AI and skill activity.

## Persistence And Continuity

- Persisted snapshots, alerts, briefings, notifications, timeline events, and logs so the shell behaves like a historical application instead of a fresh session on every launch.
- Improved startup hydration so notifications, briefings, and logs restore from local state.

## FM Radio

- Restored the signal map as a station-to-home visualization driven by the operator’s saved home endpoint.
- Upgraded the map rendering to use real world land geometry with an orthographic globe instead of placeholder continent shapes.
