# HELM v6.0.0

Released: 2026-10-21. Release page: [HELM v6.0.0](https://github.com/dark-vector-cognition/helm/releases/tag/v6.0.0).

HELM V6 adds supervised agent runs, the Signal interface and a signed Mac build.

## Highlights

- Supervised local runs for Claude Code, Cursor and Codex, with an explicit workspace, permission mode and time limit. A returned result waits for your review. Run journals recover after a restart.
- Signal interface: graphite shell, clearer navigation and a full-width run workspace. Visuals pause when hidden and respect reduced motion.
- Briefings can pin one named model. A briefing to any endpoint outside this machine and the local network sends CPU and memory totals only.
- Optional Support HELM link. Every feature stays free.
- The macOS DMG is signed with Developer ID and notarized by Apple.
- The Windows executable is now `helm-light.exe`, so it does not collide with the Kubernetes `helm` command.

## Install on macOS

1. Download [`helm-6.0.0-arm64.dmg`](https://github.com/dark-vector-cognition/helm/releases/download/v6.0.0/helm-6.0.0-arm64.dmg) (Apple Silicon).
2. Open the DMG and drag HELM to Applications.
3. Open HELM from Applications.

## Known limits

- Windows managed launch is unavailable. Windows monitoring remains available.
- The Mac DMG is for Apple Silicon only.
